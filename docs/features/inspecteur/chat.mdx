# Chat

Appel principal vers le modèle (`chat/completions`). Un tour de réponse peut en produire **plusieurs** : un par aller-retour tant que le modèle demande des outils (3 au plus).

Badge d’origine fournisseur (aujourd’hui **Mistral**). Le modèle appelé est affiché au dépliage.

## Les cartes `role` du payload

Chaque entrée de `messages` s’affiche comme une petite carte **role** + texte. Exemples :

<MessageApercu role="system">
  Vous êtes l’assistant du cabinet… Date du jour : 6 octobre 2026. Résumé glissant : …
</MessageApercu>

<MessageApercu role="user">
  Peux-tu me résumer le PLU de Castries ?
</MessageApercu>

<MessageApercu role="assistant">
  Je vais chercher les informations à jour…
</MessageApercu>

<MessageApercu role="tool">
  {`{ "resultats": [{ "titre": "PLU Castries", "url": "https://…" }] }`}
</MessageApercu>

Ordre typique dans un **premier** Chat du tour : `system`, puis la fenêtre (`user` / `assistant`), puis le `user` du message courant. Un `tool` n’apparaît qu’à partir du Chat suivant, une fois l’outil exécuté.
